# TWO WORLDS — Реальная сцена Миры у зеркала, анимация v2

**Результат 29.10.2026:** на приватных уже существовавших изображениях
выполнен и целиком декодирован новый 10-секундный анимационный тест.

### Источники

В персональной приватной библиотеке найдены уже созданные изображения:
- `Мира со спины в синем свитере.png`: **вид спины уже действительно был**,
  формат 1024×1536. Это прошлое изображение, **не новый запуск FLUX**.
- `Мира: чистый прозрачный силуэт.png`: PNG 1024×1536 с альфа-каналом,
  пригодный для разметки модели.
- `Мира у зеркала, Лира внутри.png`: оригинальная композитная сцена
  941×1672 с физически правильной постановкой (спина Миры к зрителю, Лира
  за зеркалом). В коде GitHub лежит только исполнитель, сами изображения
  публично не загружаются.

### Фактически выпущенный результат (хранится приватно)

`TWO_WORLDS_MIRA_LYRA_MIRROR_V2_10s.mp4`
— H.264/AAC, **1080×1920, 24 кадра/сек, 240 кадров, 10 сек**.
Исходная композиция 941×1672; кадры деформировались на 720×1280, а
экспортированы увеличением через Lanczos. ЭТО НЕ native 1080p исходник.

В сцене использованы существующие полноценные образы Миры и Лиры,
их верная география у зеркала, непрерывное деформирование области
персонажей (не отдельные летающие наклейки), движение камеры,
эффекты стекла и дождя. В клип добавлена синтезированная новая звуковая
атмосфера без реплик. Проход полного MP4 декодирования — пройден.

### Настоящий rear-view rig — подготовлен из приватного пользовательского изображения

Приватно получены `rig.json`, 14 PNG-слоёв в единой координатной системе
1024×1536 и оригинал, закреплённый SHA-256. Полная маска 14 частей при
суммировании **побитово совпала** с исходной альфой; ни один исходный пиксель
альфы не теряется и не дублируется. В пакете есть контактная схема суставов.

Но: разметка частей **исходно анатомическая ручная**, а скрытые участки
суставов пока не нарисованы отдельно. Риг технически пригоден для Studio,
но не подтверждён как качественная живая модель — **не утверждать**, что
профдвижение суставов доказано.

### Как воспроизвести тест из GitHub (без публикации исходной графики)

```bash
pip install -r requirements.txt -r requirements-cinematic.txt
python -m studio.private_real_art_scene \
  --scene /PRIVATE/Мира_у_зеркала_Лира_внутри.png \
  --output /PRIVATE/TWO_WORLDS_MIRA_MIRROR_REAL_REVIEW.mp4
```

Это новый интегрированный код Studio, **не** совершенно другой генератор
вместо Studio. Требует FFmpeg, OpenCV, Pillow, NumPy; размер и количество
кадров фиксируются, постпроверка полного декодирования обязана пройти.
Отсутствующий источник — блокирующая ошибка. Никаких прав публикации
или статусов художественной приёмки код не присваивает.

### Художественные ограничения

Существующий выданный видеотест **не** содержит:
- произвольных движений головы в 3D и независимого полноценного рига Лиры;
- качественного подъёма руки до соприкосновения ладоней;
- доказанной ходьбы с постановкой стоп и сохранением объёма тела;
- профессионального уровня анимации всего тела.

Видеотест действительно создан, однако этого ещё недостаточно, чтобы
называть сцену окончательно улучшенным профессиональным пилотом.
Для следующего художественного прохода требуются качественно дорисованные
отдельные суставы, новые ключевые позы/видеоусловление и проверка
зрителем первого до последнего кадра. Никаких слепых автослияний и
публикаций в TikTok.
