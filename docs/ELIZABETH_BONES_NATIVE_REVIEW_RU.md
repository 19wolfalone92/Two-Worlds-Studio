# Elizabeth Bones — нативная проверка TWO WORLDS STUDIO

Студия собирает тестовый ролик **сама**, используя `studio.hybrid_master.produce`; внешние редакторы InVideo, CapCut и т. п. не вызываются. Три результата: MP4, SRT, отчёт JSON.

**Разница между двумя режимами принципиальна.** Режим `--fixture` создаёт исключительно нарисованные кодом условные изображения Элизабет и Кости — это тест видеосборки, **не** подтверждение фотореалистичной графики, мимики или движений. Ни один кадр не считается утверждённым. Тестовый MP4 нельзя публиковать.

Для настоящего промо подготовьте приватно (вне публичного GitHub) семь утверждённых изображений `S00.png` … `S06.png`; при необходимости допустимы jpg/webp. Все семь кадров должны быть разными по ракурсу/действию, с сохранением внешности и анатомии персонажей. Для полного озвученного варианта потребуются шесть настоящих русских записей `voice_S01.wav` … `voice_S06.wav`, по одной записи для каждой реплики. MP3/M4A/FLAC тоже допустимы.

Команда для настоящих приватных ассетов:

```bash
python -m tools.elizabeth_native_promo --media private/eb01 \
  --output private/eb01/EB01_NATIVE_REVIEW.mp4 --require-all-voices
```

Запуск студийного **технического** теста без личных изображений:

```bash
python -m tools.elizabeth_native_promo --media /tmp/eb01_technical \
  --output /tmp/EB01_NATIVE_TECHNICAL.mp4 --fixture
```

Обе команды работают через нативный движок TWO WORLDS STUDIO. Для работы нужны `requirements.txt`, `ffmpeg`, `ffprobe`, шрифты DejaVu.

Зафиксированы семь планов S00–S06, русские реплики оригинального сценария, примерно 18,475 секунды, вертикальный размер 576×1024, частота 24 fps. Тестовый режим **не имеет озвучки и естественной нейросетевой анимации**. Если хотя бы один обязательный исходный кадр отсутствует, обычная сборка прерывается — подмены техническим рисунком без отдельного `--fixture` не допускаются. Встроенный контроль полноты озвучивания запрещает объявить ролик законченным при отсутствии любой реплики.

Упрощённый тест собирается GitHub Actions workflow `elizabeth-native-preview.yml` (артефакт `Elizabeth_Bones_EB01_NATIVE_STUDIO_TECHNICAL_ONLY`). Чек-лист для готового фильма включает ручную проверку внешности, поз, речи, губ, звука и прав. Никакой публикации в TikTok/Instagram.
