# Реальное движение вместо слайдов — LTX 2B GPU bridge

**Status: ADAPTER WRITTEN / REAL GPU OUTPUT NOT YET TESTED.** Этот модуль — опциональное дополнение существующей студии TWO WORLDS, не новый репозиторий.

## Зачем
Первый проморолик Elizabeth Bones на 32 секунды был фактически слайд-шоу: фото, движущийся масштаб, подписи и музыка, но не говорящие персонажи. Это не исправляется одним FFmpeg. Для **реально нового видеодвижения** нужен I2V-генератор, моделирующий изменения позы, лица и окружения между кадрами.

Официальная открытая реализация **Lightricks LTX-Video** содержит 2B image-to-video модели, включая `ltxv-2b-0.9.8-distilled`, и документирует команду `inference.py --conditioning_media_paths ... --conditioning_start_frames 0`. Её авторский код распространяется отдельно от весов; проверьте **конкретную лицензию весов** перед коммерческим применением.

Источники: https://github.com/Lightricks/LTX-Video и https://huggingface.co/Lightricks/LTX-Video . Технические ограничения, производительность, доступность моделей и GPU-квоты меняются.

## Как устроен безопасный запуск

Нужны локально заранее загруженные и разрешённые владельцем:
- официальный checkout LTX-Video с `inference.py` и оригинальным `configs/ltxv-2b-0.9.8-distilled.yaml`;
- реальные checkpoint `ltxv-2b-0.9.8-distilled.safetensors`, spatial upscaler `ltxv-spatial-upscaler-0.9.8.safetensors`;
- локальная T5 PixArt text encoder директория с `text_encoder/config.json`, `tokenizer/tokenizer_config.json` и нужными файлами весов;
- приватная фотография или художественный референс Элизабет/Кости, права на использование;
- GPU с CUDA (первый тест ориентирован на **T4 16 ГБ**, но успешная генерация пока **НЕ доказана**).

Запуск с личным референсом вне публичного репозитория:

```bash
python -m studio.offline_motion_ltx \
  --ltx-repo /private/LTX-Video \
  --weights /private/ltx2b-model \
  --image /private/refs/kostya.png \
  --output /private/outputs/kostya-shot-01 \
  --prompt "A friendly stylish skeleton tilts his head toward Elizabeth, moves his jaw while speaking, opens his eyes with a comic expression, warm gothic atelier, cinematic dolly, rich lighting."
```

Без `--execute` **не грузится GPU**, выдаётся только отчёт о локальных файлах/блокировках. С `--execute` запускается LTX внутри пользовательского GPU окружения, без скачиваний (`HF_HUB_OFFLINE=1`, `TRANSFORMERS_OFFLINE=1`). По умолчанию — короткий тест 512×896, 81 кадр (8×10+1), 24 fps, с CPU offload. На выходе — PRIVATE непроверенный MP4 и контрольная сумма, а **не готовый к публикации** промо.

## После GPU

1. Отдельно просмотреть 5 секунд на дефекты лица/челюсти/пальцев, идентичность референсу, естественность поведения; при плохом качестве отклонить.
2. Добавить естественную русскую речь через **уже существующую** отдельную Qwen3-TTS-ветку студии; проверить на слух. Аудиодорожка LTX 2B отдельно **не создаётся**.
3. Согласовать тайминг голоса и артикуляции (сам LTX из фотографии **не гарантирует lip-sync**); решить синхронизацию отдельным проверенным инструментом при наличии модели и прав.
4. Только после реальных кадров собрать 9:16 1080×1920, музыку, диктор, титры; прогнать `studio.promo_quality_gate` и ручной review.
5. Ни одна команда не меняет main, не запускает платное API, не публикует контент, не загружает личные фотографии в GitHub.

Остающиеся ограничения: генератор, CUDA-обвязка и веса пока не установлены в ChatGPT runtime, Kaggle T4 конкретно для этого LTX config не проверена. Эффективная VRAM, резолюция и художественный результат требуют **реального GPU теста**, а не декларации.
