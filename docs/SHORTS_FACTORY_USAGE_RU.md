Версия: 2026-10-30. Режим: локальный офлайн-монтаж из РЕАЛЬНЫХ медиафайлов, без автоматического постинга.

1. [C — дорожная карта](SHORTS_C_ROADMAP.md)
2. [B — техническое ТЗ](SHORTS_B_SPEC.md)
3. [A — архитектура](SHORTS_A_ARCHITECTURE.md)

Студия **не** перезаписывает историю и **не** обещает фотореалистичные кадры без реальных генераторов. Следующие команды не покупают кредиты и не обращаются к платным API.

## 1. Подготовить PRIVATE Batch03

Исходный пользовательский архив распаковать в приватную локальную директорию, содержащую `stories_ru/`, `narration_ru/`.

```bash
python -m studio.shorts_batch --kit /private/Story_Glitch_Batch03_RU_Production_Kit --out /private/two_worlds_jobs
```

Команда создаёт подпапки `13` ... `18` с `project.json`, `story.txt`, `shot_plan.json` и `queue.json`. Исходные истории копируются **побайтно**, в manifest фиксируется SHA256. Статус на этом этапе — **ASSETS_PENDING**, а не `DONE`.

В каждой `project.json` заполнены пути к ожидаемым материалам для всех 8 сцен:
- `images/scene_01.png` ... `images/scene_08.png` — настоящие фотореалистичные кадры из выбранного генератора с согласованной внешностью.
- `voices/scene_01.wav` ... `voices/scene_08.wav` — настоящая русская речь из доступного TTS. Нельзя подставлять синтетический тестовый звук.
- `subtitles` — реальные start/end-секунды в пределах конкретного WAV, полученные через TTS alignment / forced alignment; НЕ оцениваются по количеству букв.
- Дополнительно можно указать `music: "music/scene_01.wav"` — лицензированный музыкальный фон сцены. Музыка реально приглушается по сигналу голоса (sidechain ducking).
- Если Runway или другой разрешённый генератор сделал живой клип, сцена может содержать `motion_video: "motion/scene_01.mp4"` (плюс обычную `image` для обложки): движок использует настоящие видео-кадры вместо статичного zoompan и не зацикливает короткие клипы.

Рекомендации голосов из подключенного каталога, **не прослушанные и без автогенерации**: `audio/story_ru_voice_candidates.json`.

## 2. Проверить готовность медиа

```bash
python -m studio.shorts_factory --project /private/two_worlds_jobs/13/project.json --out /private/exports --dry-run
```

При отсутствующих медиа команда выдаст **BLOCKED** и причину. Она не делает вид, будто заглушки — настоящая речь или картинки.

## 3. Собрать видео

```bash
python -m studio.shorts_factory --project /private/two_worlds_jobs/13/project.json --out /private/exports
```

В `/private/exports/work_13/` появятся:
- `final.mp4` — H.264/AAC, вертикаль 1080×1920, вшитые субтитры, плавные движения камеры;
- `cover.jpg` — отдельная титульная цветная обложка;
- `subtitles.srt` — русские субтитры;
- `qa_report.json` — проверка технического кодека, полного декодирования, первого кадра, длительности;
- `receipt.json` — SHA256 исходного сценария, исходных медиа и готового MP4.

**Выход имеет статус `REVIEW_REQUIRED`, а не `PUBLISHED`.** Авторские права, убедительность голоса и фотореализм проверяются отдельно. TikTok и Metricool не затрагиваются.

## 4. Проверить код

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p "test_shorts_*.py" -v
```

Дополнительно потребуются FFmpeg, FFprobe и сборка FFmpeg с фильтром subtitles/libass. Тест `--technical-smoke` предназначен **только для короткого искусственного двухсценного теста**, чтобы проверить фактическое создание MP4, но никогда не служит доказательством выпуска реальной истории.

## Истинные ограничения

- Аудио и визуальные генераторы работают только при наличии доступных законных моделей/кредитов/GPU.
- Из доступного текста Batch03 есть 6×8 = **48 сценарных сцен**; сам по себе текст не содержит 48 готовых изображений, 48 живых русских озвучек или их реальных таймкодов.
- Только Work/подключённые провайдеры могут сгенерировать исходники, а финальные субъективные решения остаются за владельцем. Команда рендера не обходит подписку, квоты или необходимость проверки материалов.
