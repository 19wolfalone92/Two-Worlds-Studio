# Two Worlds Studio — автономный локальный конвейер без кредитов API

Версия 2026-10-30. Основан на `feat/shorts-factory-cba-20261030` / PR #21.
Функции здесь предназначены для **коротких русскоязычных историй Story Glitch**,
а не для изменения сценариев или производства отдельного фантастического сериала.

## Что реально реализовано

- `studio/offline_batch.py`: одна команда на шесть историй из приватного Batch03, последовательная работа без конкуренции за GPU, диагностика и сохранение прогресса.
- `studio/autonomous_factory.py`: 8+ сцен на историю, сверка с исходным текстом и SHA-256, повторный запуск без перегенерации удачных файлов, атомарная запись JSON, список отсутствующих ассетов, разрешение на рендер **только после фактической готовности**.
- `studio/offline_media.py`: реальная локальная генерация изображений из **уже скачанных** весов `FLUX.2-klein-4B` через Diffusers; `Qwen3-TTS-0.6B-CustomVoice` из локальных весов без внешнего API; фразовые субтитры по фактически синтезированной длительности сегментов; собственная синтетическая фоновая музыка WAV с настроениями и сохранением хеша.
- `studio/shorts_factory.py` (базовый PR #21): реальная сборка MP4/SRT, движение камеры, вставка внешних движущихся фрагментов, ducking музыки, цветная обложка, полный FFmpeg decode, checksums, выдача только на review.
- Чистый публичный GitHub: только код и документация; сценарии, веса, голоса и изображения остаются приватными.

## Почему это автономно, но не бесплатно по ресурсам

Работа после **однократной** установки локальных весов не требует ElevenLabs, Runway, Descript, invideo, кредитов или обязательной ежемесячной подписки. Но потребуются собственная видеокарта/компьютер, электричество и место на диске. Скачивание моделей один раз требует интернета и принятия лицензии. На обычном телефоне полноценный GPU-конвейер не протестирован и не поддерживается.

### Минимальные возможности и реалистичные требования

| Режим | Оборудование | Что получится |
| --- | --- | --- |
| Без GPU | CPU, Python, FFmpeg | Просмотр очереди, оригинальная музыка, сборка и проверка из уже готовых реальных изображений/русских WAV |
| Локальные изображения | Желательно NVIDIA **12–16+ ГБ VRAM** и ОЗУ для offload | FLUX.2 Klein 4B, генерация 8+ кадров на историю; лица требуют просмотра |
| Локальная речь | NVIDIA GPU (6–8+ ГБ как предварительный ориентир) или медленный CPU | Qwen3-TTS: русские фразы, стили, реальные границы сегментов; обязательное прослушивание |
| Реальное диффузионное видео | Обычно отдельная NVIDIA **24+ ГБ VRAM** для Wan2.2-TI2V-5B | Короткие клипы через дополнительный локальный движок; в этом PR пока **не** реализован прямой Wan-адаптер |
| LTX-2.5 | По официальной документации **32+ ГБ VRAM**, много RAM/SSD | Качественное локальное видео; сейчас не входит в базовый автоматический маршрут |

Оценки GPU не являются обещанием успешного запуска на любой конкретной карте, CUDA/driver и модели. В этом окружении реальный CUDA отсутствует: проверены контракт, исходники, звучание тестовых WAV и FFmpeg, **не** реальный Qwen/FLUX GPU-инференс.

**Коммерческие права:** FLUX.2 Klein **4B** использует Apache-2.0; **9B** и FLUX dev без дополнительной лицензии не использовать для коммерческого проекта. Qwen3-TTS CustomVoice 0.6B лицензируется Apache-2.0. Соблюдать исходные лицензии, права на текст, голос и изображения. Программная генерация музыки не доказывает отсутствие сходства со всеми существующими мелодиями: итоговые дорожки нужно прослушать.

## Разовая настройка

1. Установить Python 3.11/3.12 и FFmpeg + ffprobe (с `libass`/`subtitles`).
2. Установить `requirements.txt` репозитория и дополнительные Python-пакеты для выбраных локальных моделей:
   `pip install soundfile qwen-tts` и подходящую под CUDA версию PyTorch, `pip install -U diffusers transformers accelerate`.
3. **Вручную**, один раз скачайте официальные разрешённые веса в `PRIVATE_MODELS/voice/` и `PRIVATE_MODELS/image/` (папки должны содержать `config.json`). Не помещать веса и приватные истории в публичный GitHub. У Qwen3-TTS также есть speech-tokenizer компоненты, скачиваемые вместе с моделью.
4. Исходные материалы Work Batch03 распаковать и импортировать в приватную рабочую директорию:

```bash
python -m studio.shorts_batch \
  --kit /PRIVATE/Story_Glitch_Batch03_RU_Production_Kit \
  --out /PRIVATE/production_queue
```

## Команды

Проверка готовности 48 сцен, без вызова генераторов:

```bash
python -m studio.offline_batch --queue /PRIVATE/production_queue --status
```

Один автономный проход **без платных сервисов** — изображения, голос, оригинальная фоновая музыка, монтаж:

```bash
python -m studio.offline_batch --queue /PRIVATE/production_queue \
  --models-root /PRIVATE/models --out /PRIVATE/exports \
  --images --voices --device cuda
```

Продолжение после сбоя, без повторной генерации готовых файлов: просто запустить команду ещё раз. Модель грузится лениво и повторно используется внутри одного процесса. Для уже готовых изображений отключить `--images`; для уже готовой озвучки отключить `--voices`. Можно отдельно запускать по одной истории:

```bash
python -m studio.autonomous_factory --project-dir /PRIVATE/production_queue/13 \
  --models-root /PRIVATE/models --out /PRIVATE/exports --images --voices --music --render
```

В статусе `ASSETS_PENDING` указан точный дефицит. `REVIEW_REQUIRED` означает наличие технически проверенного MP4, но не качество уровня фильма или разрешение публиковать. **Публикация нигде не реализована.**

Если вся партия реально собрана и проверена, сформировать ZIP из реальных результатов:

```bash
python -m studio.offline_batch --queue /PRIVATE/production_queue \
  --out /PRIVATE/exports --package /PRIVATE/TwoWorlds_Review_6_RU.zip
```

Команда откажется делать вид, что шесть видео готовы, если хотя бы одного настоящего MP4/хеша/QA нет.

## Что НЕ реализовано и что ограничивает качество

- Нет гарантированного соблюдения идентичности лиц; optional `reference_images` для FLUX помогает лишь при реальной поддержке model/conditioning, но не удостоверяет совпадение.
- Нет настоящей произвольной 3D-анимации, Blender-рига или длинного многокадрового диффузионного видео в локальном маршруте. Технический Ken Burns/2.5D не равен движущемуся человеку. Внешние готовые реальные клипы можно подавать в `motion_video` монтажера.
- Процедурная фоновая музыка — оригинальный простой ambient, **не** профессиональная партитура. Опциональный локальный генератор ACE-Step 1.5 (MIT) подходит для следующего этапа улучшения; пока не интегрирован.
- Субтитры синхронизируются по **длительности фраз**, измеренных в настоящем WAV, но не по фонемам. Требуется отдельный ASR/forced alignment для точного word-by-word.
- Нет финальной автоматической художественной оценки, контроля всех лицензий или автоматической публикации. Исключено ложное `approved=true`.

## Тесты

```bash
python -m unittest discover -s tests -p 'test_shorts_*.py' -v
python -m unittest discover -s tests -p 'test_offline_*.py' -v
```

Тесты локальных моделей используют **подставные модели** без реального GPU и не доказали качество голоса и генерации фотореалистичных изображений. Render smoke использует настоящие тестовые WAV и синтетические PNG, **не** заявлен как готовый ролик.

## Работа с мобильного

Телефон может быть пультом: запускать Python-обработчик по SSH или через браузерный интерфейс домашнего ПК. Само тяжёлое создание изображений/видео без дискретного GPU на телефоне не обещается. Подключение неограниченной собственной GPU-машины избавляет от лимитов подписок, но не от физических пределов скорости и памяти.
