# Two Worlds Studio — Мужчина машет рукой, проверенный видеопилот

23 ноября 2026. Отдельная демонстрация студии; **не путать с серией Elizabeth Bones**.

## Исходный контекст пользователя

Сохранены требования, зафиксированные 21–22 ноября:
- Лысый мужчина в прямоугольных чёрных очках, короткая борода, светлая футболка.
- Студийная комната с книгами и растением, фиксированная камера.
- Улыбка, естественный небольшой поворот головы и подъём/взмах/опускание правой для зрителя руки.
- Никаких «танцующих» бороды и оправы, шевелящихся полок, замороженной головы, самостоятельного плавания конечностей или превращения пальцев.
- **Весь персонаж остаётся оригинальной последовательностью**, включая живые движения шеи, улыбку и руку; не заменять голову застывшей маской.
- Поскольку исходный анимированный материал уже создан за предыдущие дни, использовать лучший предыдущий исходник, а не ухудшенный 2.5D puppet V9. Должен быть реальный видеофайл, а не набор слайдов.
- По возможности 1080×1920, 60 FPS; не утверждать, что простой апскейл добавил деталей.

## Студийный движок и фактическая генерация

Новый локальный движок `studio.stable_wave` (CLI `python -m studio.stable_wave`) получает уже сохранённую пользователем последовательность `wave_64_source_smooth_60fps.mp4` из его приватной библиотеки. Источник не загружается в публичный GitHub.

Исходный проверенный SHA-256:
`bc8051c3e116b694f7a2f141fee6d632393efb59fb77d30b1472ec51a483fa8b`.

Метод: каждый кадр человека остаётся исходным кадром; только необитаемая область фона заменяется постоянной декодированной пластиной с мягкой пространственной границей. Нет замены лица, интерполяции новых кадров, 3D-риггинга и фиктивного нейросетевого запуска. Результат затем кодируется H.264 CRF17/yuv420p, Lanczos доставочный апскейл. Сам исходный клип **уже содержал ранее интерполированные кадры**, и новый проход этого не отменяет.

Реальный результат, полученный локально через написанный модуль:
- MP4: `Two_Worlds_Studio_Man_Wave_1080x1920_60fps.mp4`.
- 1080×1920, 60 FPS; 190 декодированных и 190 различных RGB-кадров; длительность 3,167 секунды.
- Полное FFmpeg `-xerror` декодирование: PASS.
- Среднее межкадровое отличие в ROI взмаха руки: 6,121 уровней RGB, p95 = 17,175: рука **не заморожена**.
- Средняя абсолютная разница защищённого участка лица относительно того же кадра исходного видео после масштаба: 1,847 уровня; руки: 1,686. Лицо и пальцы не подменялись новым неподвижным изображением.
- Контрольная фоновая область (строгая ROI полки): среднее отклонение от первого кадра снизилось с 0,4553 до 0,0545 уровня RGB.

Видеоролик и полный технический JSON отчёт оставлены в файловой выдаче текущего разговора; **не опубликованы**. GitHub содержит только алгоритм, тесты и документированные метрики.

## Повторяемый запуск

```bash
python -m studio.stable_wave \
  --source /private/wave_64_source_smooth_60fps.mp4 \
  --output /private/Two_Worlds_Studio_Man_Wave_1080x1920_60fps.mp4 \
  --report /private/Two_Worlds_Studio_Man_Wave_QA.json
```

Требуются FFmpeg, ffprobe и `pip install -e '.[cinematic]'`. Файлы результата должны отсутствовать до запуска, входные медиа никогда не переписываются. В CI имеется настоящий короткий 150-кадровый тест FFmpeg/OpenCV без частных портретов и GPU.

## Честное ограничение

Это **студийный ремастер предыдущей анимации**, а **не новая нативная видеогенерация EchoMimic/LTX**. Поэтому любые исходные деформации бороды, пальцев или мимики внутри самого видеоматериала не считаются устранёнными. Полный художественный просмотр пользователем остаётся обязательным. Не загружать исходные портреты/видео в публичный репозиторий и не публиковать в TikTok без отдельного поручения.
