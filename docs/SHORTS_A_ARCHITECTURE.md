# A — архитектура: автономная фабрика русских коротких историй

Проверено относительно `Two-Worlds-Studio/main`, 2026-10-30. **Не** изменять существующую кодовую ветку мультсериала. Бриф самостоятельности — отдельный PR #20, работа с голоса Qwen3 RU — PR #19, Kokoro EN — PR #18.

## A1. Конвейер

```text
PRIVATE Work-approved RU scripts
          |
          v
  [ingest / hash lock] ---> [Batch manifest + missing asset report]
          |                         |
          v                         v
 [scene/identity plan] ----> [visual adapter] ---> image assets
          |
          +--> [narration adapter] ---> verified voice + cue timestamps
          |
          +--> [licensed music adapter] ---> per-scene audio beds
          |
          +--> [audio/subtitle contract check]
                          |
                          v
                 [shorts_factory]
       (shot duration from actual audio, camera motion,
        voice/music ducking, subtitles, colour cover)
                          |
                          v
                [FFmpeg / ffprobe QA]
                          |
                          v
          [atomic preview delivery + SHA manifest]
                          |
                          v
         [human artistic/licensing QA] -> (manual publish only)
```

## A2. Границы модулей

- `studio/shorts_factory.py` — независимый детерминированный верификатор ассетов + FFmpeg-монтаж + SRT + preview-package. Не содержит логики платных сервисов.
- `studio/narration_batch.py` в PR #18/19 — необязательные подключения Kokoro/Qwen3-TTS после ревью/мержа. Для нового ролика обязателен фактический русский voice-файл и фактические таймкоды.
- Позднее `studio/shorts_providers/*` — адаптеры генерации изображений/голосов (Runway/ElevenLabs/локальные модели) с собственными ограничениями квот и лицензий; не добавлять заглушки с поддельными результатами.
- `docs/SHORTS_C_ROADMAP.md` — очередность работ; `docs/SHORTS_B_SPEC.md` — проверяемые входы/выходы.

## A3. State machine

`IMPORTED -> ASSETS_PENDING -> ASSETS_READY -> RENDERING -> TECHNICAL_QA -> REVIEW_REQUIRED -> (RELEASE_APPROVED by owner)`. При ошибке: `BLOCKED`, с указанием отсутствующих артефактов и без записи финального MP4.

Требования: относительные защищённые пути, immutable исходники, зафиксированные SHA, временные output, запрет overwrite, без дублей при повторе, честный `dry-run`, создание технической квитанции.

## A4. Сохранение данных и восстановления

- Входные `project.json`, `story.txt`, `images/`, `audio/`, `music/` находятся вне публичного GitHub.
- Команды не уничтожают входные WAV/изображения и не переписывают `story.txt`.
- Выходная папка публикуется внутри локального приватного хранилища только после успешной проверки. При падении временная папка удаляется, входы сохраняются.
- Один и тот же ID и входной хеш не может тихо заменить уже готовый комплект. Вариант результата — новый ID или явная пересборка в отдельную папку.

## A5. Расходы и источники качества

- Сначала повторно использовать реальные существующие изображения, записи и лицензированную музыку; пользователь уже оплатил/согласовал такие материалы.
- Бесплатные локальные `FFmpeg`, `Pillow`, `ffprobe` — базовый путь, не требует API-кредитов.
- GPU-инференс и плагины — только когда доступны, легальны и не требуют непредусмотренной оплаты.
- Профессиональность голоса/лиц нельзя доказать кодом: требуется хотя бы одно ручное прослушивание/просмотр.

## A6. Контракт CI

- Тесты без API, GPU, крупных моделей и непубличных сценариев.
- Smoke render использует оригинальные синтетические изображения и тестовый звук **только** для технического контроля и никогда не маркируется как реальная история.
- Real Batch 03 финализируется только при фактическом предоставлении всех сцен, озвучки, выравнивания и аудио. Статус `BLOCKED` корректен, если исходные медиа отсутствуют.
