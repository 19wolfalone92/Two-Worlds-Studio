# FREEVIDEO — ГЛУБОКИЙ АУДИТ ИЗОЛИРОВАННОГО ПРОТОТИПА
Дата: 23 ноября 2026 г.

## Область проверки

Только экспериментальные файлы `experiments/freevideo_t4/` и отдельный
CPU-only workflow `.github/workflows/freevideo-t4-offline.yml` ветки
`research/freevideo-t4-adaptive-20261123`. Исходники, рабочие процессы
основной Two Worlds Studio, `main`, ее модели, личные ресурсы Kaggle и
публикация в TikTok не менялись.

Freevideo — **временное имя экспериментального конвейера**, а не собственная
обученная модель, не форк MiniMax H3 и не внедрение Video DeltaNet.

Проверка выполнена на исходном коде и автономных тестах. Отдельного
реального GPU T4 или запуска ComfyUI в данном сеансе не было.

## Проверенные цепочки и найденные первопричины

| Зона | Первопричина/риск до исправления | Исправление | Объективная проверка |
| --- | --- | --- | --- |
| CUDA и VRAM | Данные локального CUDA-процесса могли не совпадать с GPU фактического ComfyUI | T4-only, проверка Compute Capability, реального VRAM, отклонение NaN/невозможных значений; сверка ComfyUI `/system_stats` | Мок-тест правильного устройства и нескольких несовместимых ответов |
| CUDA simulation | Симуляция могла быть ошибочно воспринята как GPU-доказательство | `--simulate-t4` доступен только в `plan`, выполнение GPU требует реальную T4 | Отдельный отрицательный тест |
| Совместимость | MiniMax H3/VDN не поддерживаются на данном профиле T4 | Явное исключение H3, только существующий Wan2.2 TI2V-5B, без BF16 на T4 | Проверки профилей и параметров |
| Plan → native bridge | Одной синтетической оценки ресурсов недостаточно для подтверждения выполнения | Сохранен проверяемый вызов `studio.comfy_neural`; отдельный CI smoke-test реального `wan22_workflow` для всех четырех конфигураций | Mock bridge в локальных тестах, bridge contract в CI пока без подтвержденного результата |
| Preview → final | До изменения было достаточно любого файла MP4 с вручную введённым хешем | Требуются 2 связанные квитанции, подтверждение фактического инеренса, совпадение референса, seed, prompt, SHA-256 и видео-геометрии | Отрицательные тесты отсутствия/порчи квитанции; 2-stage handoff |
| Реальные кадры | Проверялась только отметка «MP4 есть» | `ffprobe` декодирует и считает кадры, ширину/высоту/FPS; проверка native 24 FPS | Настоящий короткий синтетический MP4, а не скриншот |
| Повторный запуск | При повторе после сбоя можно случайно перезаписать подтвержденный видео-результат | Принудительно новые имена, no-overwrite для MP4 и квитанций, запрет автоматического ретрая | Тест неизменяемости существующего MP4 |
| Безопасность файлов | Нормализация пути делала проверку `.is_symlink()` бесполезной | Лексический и разрешённый путь, отказ для file-symlinks, запрет записи результатов в публичный Git | Тест симлинков и репозиторных путей |
| Соединение ComfyUI | Локальная проверка не гарантировала соответствие с GPU сервера | Loopback-only HTTP, никаких HTTP redirects, no-proxy и bounded `/system_stats` | Тест запрещённых адресов и GPU mismatch |
| JSONL статистика | NaN/искажённый JSON могли портить медианы или выбрасывать необработанные исключения | Лимит размера, строгая валидация успешных записей, streaming-read, реальные затраты | Тесты медианы, NaN, повреждения |
| Статус GPU | Ошибка записи необязательного журнала могла ошибочно выглядеть как провал генерации | Подтвержденный MP4 сохраняется, отдельное предупреждение о telemetry | Тест сбоя накопителя |
| Качество персонажей | Булев `approved` не является оценкой реального видео | Отдельная ручная оценка каждого клипа; не считать approval автоматическим зрением | Код не выполняет и не притворяется человеческим визуальным анализом |

## Фактическое выполнение

- Python syntax compilation: пройдено в локальном окружении.
- CPU `unittest discover`: **21 из 21 пройдены** в локальном окружении.
- Тестирование `ffprobe`: реальный синтетический MP4 разобран, испорченный отклонён.
- Preview → final: **сквозной программный тест с подменой GPU-движка** пройден; нативная генерация не заявляется.
- План на симуляции NVIDIA T4: возвращает
  `HEURISTIC_PLAN_NOT_BENCHMARKED`, реальный GPU не используется.
- Реальное отсутствие CUDA в окружении: `plan` без симуляции вернул
  `BLOCKED: No accessible CUDA GPU at requested index`.
- GitHub Actions workflow добавлен/усилен, но его успешное завершение
  **не подтверждено** этим отчётом.
- **0 GPU запусков**, 0 изменений студии, 0 скачиваний весов, 0 публикаций.

## Что пока нельзя объявить завершённым

1. Проверка реальной доступности T4, доступной VRAM и скорости Wan2.2 на
   инфраструктуре Kaggle. Программы «автоматического переключения между
   четырьмя GPU» нет, память разных сеансов не объединяется.
2. Независимое сравнение времени расхода GPU на один **одобренный**
   ролик относительно текущего движка без предварительного просмотра.
3. Визуальное качество Элизабет/Кости: реальные кадры, лицевые черты,
   скелетная геометрия, волосы, одежда, руки, плавность, отсутствие деформаций.
4. Стойкость установки официальных весов и ComfyUI к настоящему OOM. Автоматических
   повторов нет намеренно, чтобы не сжигать квоту и не дублировать видео.
5. Проверка лицензий для реального рабочего применения, особенно при
   рассмотрении сторонних моделей. H3 не установлен.
6. Подпись квитанций и криптографическая аутентификация GPU не реализованы;
   `/system_stats` дает лишь сверку атрибутов на доверенном локальном сервере.

## Правило внедрения в основную студию

Из этой ветки **нельзя автоматически переносить всё**. Сначала должны быть
реальные контрольные генерации на T4, визуально проверенные материалы и
доказанная экономия **на один пригодный ролик**, после чего можно выборочно
портировать только подтверждённые улучшения отдельным утверждённым PR.
До этого `main` остается неизменным.
