# Freevideo — проверка технологий, совместимости T4 и ограничения доказательств

Дата исследования: 2026-11-23. Область: **только** экспериментальный Freevideo в
`experiments/freevideo_t4/`, без изменения production-студии.

## Фактически исследованные исходники

1. [FlashML-org/FreeVideo](https://github.com/FlashML-org/FreeVideo):
   самостоятельный движок для MiniMax H3 на базе Video DeltaNet (VDN-H3).
   В эксперименте Freevideo **нет** ни VDN-H3, ни MiniMax H3, ни адаптации их
   математической архитектуры к Wan2.2. Используются только исследовательские
   идеи проверки аппаратных ограничений, поэтапного запуска и контроля отказов.
2. [Wan-Video/Wan2.2](https://github.com/Wan-Video/Wan2.2):
   семейство генеративных видеомоделей. Ветвь исполняет исключительно
   Wan2.2 TI2V-5B через API-граф из `studio.comfy_neural`.
   Официальный CLI и ComfyUI имеют **разные** маршруты управления памятью.
   Нельзя переносить заявления о VRAM и времени одного маршрута на другой.
3. [Официальная документация ComfyUI по Wan2.2](https://docs.comfy.org/tutorials/video/wan/wan2_2):
   TI2V-5B поддерживает I2V; native offloading может уменьшить потребление VRAM.
   Это **основание для испытания**, но не доказательство работоспособности
   конкретного графа на выбранной T4.
4. [NVIDIA Tesla T4](https://www.nvidia.com/en-us/data-center/tesla-t4/):
   Turing, compute capability 7.5, FP16 Tensor Cores, INT8. Не считать
   BF16 и native FP8 Tensor Core kernels доступными на T4.
5. [Лицензии FreeVideo](https://github.com/FlashML-org/FreeVideo/blob/main/THIRD_PARTY_NOTICES.md):
   Apache-2.0 для кода движка, а веса MiniMax H3/VDN-H3 имеют отдельные
   условия. Никаких внешних весов или кода FreeVideo в эксперимент не скопировано.

## Таблица технологических гипотез

| Приём | T4: состояние | Реализация/исследование | Вывод |
| --- | --- | --- | --- |
| FP16 вычисления Wan 5B | Теоретически поддерживается | В `choose_plan` заявлен `fp16` | `CPU_TESTED` для плана, `GPU_NOT_TESTED` |
| Native BF16 / FP8 kernels | Неподдерживаемое T4 ускорение | Не включать на T4 | `BLOCKED` |
| ComfyUI model/component offload | Возможен по upstream документации | Реально задаётся backend, не новым планировщиком Freevideo | `NOT_TESTED` |
| T4-aware оценки VRAM | Доступны через локальный CUDA probe | Выбран один GPU, есть отказ при недостоверной VRAM | `CPU_TESTED` только с моками |
| Сверка ComfyUI / локального GPU | Возможна через /system_stats | Ветка сравнивает индекс, имя и общий объём VRAM | `CPU_TESTED` с моками; не криптоаттестация |
| SHA-256 установленного чекпойнта | CPU-операция | Обязательная сверка с частным манифестом до submission | `CPU_TESTED`, издатель не аутентифицирован |
| FP16/INT8 quantization tradeoff | Требует точных весов и совместимых backend | Квантование не включалось | `NOT_TESTED` |
| Уменьшение числа шагов | Математически возможно лишь в рамках проверенного workflow | Профили планировщика без измерения качества | `NOT_TESTED` |
| Видеостабилизация, face geometry, rigid skeleton | Требуют визуальной и/или предметной оценки | CPU pixel diagnostics только флаги, без художественных выводов | `NOT_TESTED` |
| Video DeltaNet / MiniMax H3 | Отдельный модельный стек, лицензии и аппаратная совместимость должны проверяться отдельно | Не интегрирован | `BLOCKED` для текущего execution path |
| Мульти GPU, четыре T4 | Независимые устройства без объединения VRAM | Только per-worker lock одной CUDA-карты | `NOT_TESTED` |
| Preview → Final | Отдельные генерации, НЕ upscale | Human gate, квитанции, SHA-256 и video-clock | `CPU_TESTED` (mock bridge), GPU выгода не доказана |

## Рекомендуемый реальный аппаратный эксперимент

**До запуска**: подтвердить законный Kaggle GPU runtime, конкретную карту и
свободную VRAM, локальную защищённую установку официальных весов и ComfyUI,
локальную RAM, версии драйвера/CUDA/PyTorch, контракт API-графа, целостность
весов, лицензию и отсутствие чужих GPU-процессов. Эталон персонажа должен
оставаться приватным и неизменённым.

Первым провести строго **одну** I2V-генерацию 432×768, 25 кадров, 24 FPS на
T4 — только если пройдены preflight-гейты. Если наблюдается OOM либо ComfyUI
занят, остановить запуск и сохранить доказательства. Конфигурацию нельзя
называть безопасной или оптимальной до настоящего успешного исполнения.

Следующие разрешённые испытания: фиксированные ref/prompt/seed/model/steps/
frames/VRAM и GPU hardware; сравнивать по температуре, времени, пиковому VRAM,
сбоям, кадрам/декодированию и ручной художественной пригодности. Сравнение
статистически честно только при реальных контрольных парах и учёте провалов.

## Достоверность вывода

По состоянию на момент составления **нет подтверждённого API-доступа к
приватному Kaggle runtime**, нет запуска модели на настоящей T4, нет
измеренного пика VRAM, нет настоящих нейросетевых MP4 Freevideo, нет кадров
Элизабет или Кости для независимого просмотра. Ветка является
изолированным техническим прототипом, а не готовым движком или улучшением
студии. Источники upstream не заменяют измерений на данной конфигурации.
